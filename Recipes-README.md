# 🍳 Recipes | Recipe Browsing Web App

A responsive React web application for discovering recipes, organized by category and powered by real-time data from a REST API.

🔗 **Live Demo:** [recipes-beta-dun.vercel.app](https://recipes-beta-dun.vercel.app/)

---

## ✨ Overview

Recipes is a front-end application built to make browsing recipes simple and enjoyable. It fetches both recipes and their categories directly from an external API, giving users an organized, up-to-date, and easy-to-navigate browsing experience.

## 🚀 Key Features

- **Live API Data** — Both recipes and recipe categories are fetched dynamically from a REST API, ensuring the content is always current.
- **Category-Based Browsing** — Users can explore recipes grouped by category/cuisine, making discovery fast and intuitive.
- **Smooth Navigation with React Router** — Users move seamlessly between category views and individual recipe detail pages without reloading the app.
- **State Management with Hooks** — `useState` is used to manage recipe data, categories, and UI state efficiently.
- **Fully Responsive UI** — Designed to work smoothly across desktop and mobile screens, so users can browse recipes from any device.

## 🛠️ Built With

- React.js
- React Router
- JavaScript (ES6+)
- CSS3 (Responsive Design)
- REST API Integration
